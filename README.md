# FE522 Project - Backtesting Module

This branch contains the C++ setup for the portfolio backtesting and portfolio-accounting layer.

## What This Branch Adds

- C++17 CMake build
- `Portfolio` accounting class
- `BacktestEngine` day-by-day simulator
- `CsvReader` for loading generated price CSV files
- `RebalanceStrategy` interface using inheritance and polymorphism
- Portfolio optimizer integration with inverse-volatility monthly rebalancing
- Risk module integration for metrics, Monte Carlo simulation, stress tests, and CSV reporting
- Buy-and-hold strategy
- Fixed monthly rebalance strategy
- Optimized monthly rebalance strategy
- VS Code / clangd configuration
- Small demo program that prints key risk statistics and verifies the module independently

## Build and Run

From the repository root:

```bash
cmake -S . -B build
cmake --build build
./build/backtesting_demo
```

## Generate Price Data

Python is used only as a support layer to create clean input CSV files. The
core backtesting logic remains in C++.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-data.txt
.venv/bin/python main.py
```

This writes:

```text
data/asset_prices.csv
```

## Plot C++ Outputs

After running the C++ demo, Python can also visualize Sahil's risk/reporting
CSV outputs:

```bash
.venv/bin/python plot_results.py
```

This writes presentation-ready PNG files under:

```text
figures/
```

The current asset universe is:

```text
SPY     US equities
TLT     long-duration US Treasury bonds
GLD     gold
BTC-USD Bitcoin in US dollars
```

## Module Layout

```text
include/backtesting/   Public headers for the backtesting module
src/backtesting/       C++ implementations
include/portfolio_optimizer/  Optimizer and optimized strategy headers
src/portfolio_optimizer/      Optimizer and optimized strategy implementations
include/risk/          Risk, simulation, stress testing, and reporting headers
src/risk/              Risk, simulation, stress testing, and reporting implementations
src/main_demo.cpp      Demo executable that reads data/asset_prices.csv
main.py                Python downloader for cleaned asset price CSV
plot_results.py        Python visualization wrapper for C++ output CSV files
data/asset_prices.csv  Historical price data generated by main.py
docs/                  Ownership notes
```

The demo compares buy-and-hold, fixed monthly rebalancing, and optimized monthly rebalancing, prints a compact risk snapshot, then writes risk/reporting CSV outputs for each strategy.
